# Minecraft Launcher - Красивый лаунчер на Java

## 🎮 Описание
Стильный и современный лаунчер для Minecraft с красивым интерфейсом на русском языке.

## ✨ Особенности
- **Современный дизайн** - градиенты, тени, анимации
- **Полностью на русском** - все надписи и сообщения на русском языке
- **Анимации** - плавные эффекты при наведении на кнопки
- **Выбор версии** - поддержка различных версий Minecraft
- **Индикатор прогресса** - отображение статуса запуска
- **Дополнительные функции** - кнопки настроек, модов и скинов

## 🚀 Требования
- Java 17 или выше
- Maven (для сборки)
- JavaFX 17

## 📦 Установка и запуск

### Сборка проекта
```bash
cd minecraft-launcher
mvn clean package
```

### Запуск через Maven
```bash
mvn javafx:run
```

### Запуск готового JAR
```bash
java --module-path /path/to/javafx/lib --add-modules=javafx.controls,javafx.fxml -jar target/minecraft-launcher-1.0.0.jar
```

## 🎨 Дизайн
- **Цветовая схема**: Темная тема с синими и зелеными акцентами
- **Шрифты**: Segoe UI, Arial
- **Эффекты**: Тени, градиенты, прозрачность
- **Анимации**: Плавное перемещение кнопок при наведении

## 📁 Структура проекта
```
minecraft-launcher/
├── pom.xml                          # Конфигурация Maven
├── src/main/java/com/launcher/
│   ├── LauncherApp.java             # Главное приложение
│   ├── ui/
│   │   └── LauncherUI.java          # Пользовательский интерфейс
│   └── core/
│       ├── LauncherManager.java     # Логика запуска
│       └── LaunchProgress.java      # Интерфейс прогресса
└── src/main/resources/styles/
    └── styles.css                   # Стили CSS
```

## 🎯 Функционал
1. **Главный экран** с логотипом и приветствием
2. **Выбор версии** Minecraft из списка
3. **Кнопка запуска** с анимацией
4. **Прогресс бар** для отслеживания загрузки
5. **Дополнительные кнопки**: Настройки, Моды, Скины
6. **Статус бар** с информацией о текущем состоянии

## 💡 Примечание
Это демонстрационный проект лаунчера. Для реального запуска Minecraft потребуется:
- Интеграция с Mojang API
- Система аутентификации
